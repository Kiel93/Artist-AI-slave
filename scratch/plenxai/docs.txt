Image & Video Generation (X-API-Key)
POST
/api/v1/developer/generate/image

Tạo ảnh chất lượng cao (Gemini)

TÊN	LOẠI	BẮT BUỘC	MÔ TẢ
prompt	string	BẮT BUỘC	Mô tả văn bản nội dung mong muốn.
model	string	BẮT BUỘC	ID model đã chọn: nano-banana-pro
resolution	string	Tùy chọn	Cho phép: '1k', '2k', '4k'. Mặc định: '1k'
aspect_ratio	string	Tùy chọn	Cho phép: 'Auto', '1:1', '4:3', '3:4', '9:16', '16:9'
references_urls	string[]	Tùy chọn	URLs ảnh tham khảo (tối đa 8)
negative_prompt	string	Tùy chọn	Những gì không muốn xuất hiện trong ảnh
server	string	Tùy chọn	Server slug: 'vip-01', 'business'. Ảnh hưởng routing + cost.

Ví dụ request cho Nano Banana PRO
BASH
Copy
curl -X POST https://plenxai.com/api/v1/developer/generate/image \
  -H "X-API-Key: pk_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A cinematic shot of a sunset over mountains",
    "model": "nano-banana-pro",
    "resolution": "1k",
    "aspect_ratio": "16:9",
    "references_urls": ["https://example.com/style.jpg"]
  }'
Phản hồi 200 OK

Text Generation API (X-API-Key)
POST
/api/v1/developer/text-gen/generate

Generate text bằng AI. Hỗ trợ multi-modal (text + images).

GET
/api/v1/developer/text-gen/models

Liệt kê các model text generation khả dụng.

Voice TTS API (X-API-Key)
POST
/api/v1/developer/generate/voice

Tạo giọng nói AI từ text (Text-to-Speech).

GET
/api/v1/developer/voice/models

Liệt kê các TTS models khả dụng.

GET
/api/v1/developer/voice/voices

Media Upload API (X-API-Key)
POST
/api/v1/developer/media-upload/presign

Tạo presigned URL để upload trực tiếp lên Cloudflare R2.

POST
/api/v1/developer/media-upload/confirm

Xác nhận upload & push image lên Cloudflare Images CDN.

POST
/api/v1/developer/media-upload/direct

Upload server-side (base64) cho file nhỏ.

DELETE
/api/v1/developer/media-upload/{media_id}

Xóa media đã upload (R2 + DB).

Remove Background API (X-API-Key)
POST
/api/v1/developer/remove-background

Xóa nền ảnh (đồng bộ). Trả về URL ảnh đã xóa nền ngay lập tức.

POST
/api/v1/developer/remove-background/batch

Xóa nền nhiều ảnh cùng lúc (tối đa 10). Xử lý đồng thời, trả về tất cả kết quả.
